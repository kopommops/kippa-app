# Pelo Finance — 90-second demo video script

**Target duration:** 80–88 seconds. The hackathon checklist says the video must be **less than 90 seconds**, so do not record a long intro or leave a silent tail.

## Recording plan

| Time | Screen | Narration |
|---|---|---|
| 0–8 sec | Landing page and Pelo Finance logo | “This is Pelo Finance: make your money story visible. We’re building for owner-operated businesses and irregular earners who need more than a balance—they need to understand what may happen next.” |
| 8–20 sec | Open synthetic demo, show overview and recent activity | “The demo lets us explore the product safely with synthetic data. Overview and Activity show the money coming in and going out without connecting a real bank account.” |
| 20–32 sec | Forecast and lean-week scenario | “The seven-day outlook helps users think ahead. A lean-week scenario shows how a quieter period could affect cash, while keeping assumptions visible.” |
| 32–43 sec | PeloScore section | “PeloScore is an illustrative financial-consistency signal. It explains selected factors; it is not a credit score and has not been statistically validated.” |
| 43–58 sec | Sign in to the prepared demo account; show private Overview and Activity | “In the private workspace, users can manage a business profile and enter test financial records. The hosted backend and Supabase database support persistent account data.” |
| 58–70 sec | Peloyame tab; submit a prepared question about the displayed test data | “Peloyame uses Groq to provide bounded, read-only explanations grounded in the available financial context. It cannot move money or make lending decisions.” |
| 70–80 sec | Simulated bank connection; trigger a clearly labelled incoming or outgoing event and show notification | “The bank connection is a simulation, not a live bank integration. It demonstrates how an event could update activity and notifications.” |
| 80–87 sec | Closing slide with live URL and GitHub QR/link | “Pelo Finance is a working hackathon MVP with a clear path to customer validation and approved future integrations. Thank you.” |

## Capture checklist

- Record at 1080p landscape if possible; keep the browser zoom and window size consistent.
- Use the pre-created test account. Do not display the password manager, environment variables, Supabase dashboard or API keys.
- Prepare a sample income/expense record and a Peloyame question beforehand to avoid typing delays.
- Keep the simulated-bank label visible in the recording.
- Use hard cuts between sections. Remove pauses and any loading delay that does not prove something important.
- Show the live URL and GitHub repository clearly on the closing frame.
- Export and check the actual file duration. Target 85 seconds; the submitted video must remain below 90 seconds.
